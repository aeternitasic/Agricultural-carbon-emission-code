# 农业碳排放量与碳排放效率计算代码

本仓库整理了中国 31 个省级地区 2011—2024 年农业碳排放量（ACE）和农业碳排放效率的计算程序。碳排放量由农业投入、生产过程和畜禽养殖等指标及相应系数计算；效率值采用包含非期望产出的超效率 SBM 模型，逐年求解。

仓库主要用于展示计算流程和代码实现。这里没有收录完整的原始 Excel 输入数据，也没有随仓库发布研究论文或政策效应结论。

## 计算流程

1. `config.py` 定义省份分组、碳排放指标与系数，以及效率模型的投入、期望产出和控制变量。
2. `excel_io.py`、`panel.py` 读取并对齐省份—年份数据；`compute.py` 计算农业碳排放量。
3. `sbm.py` 以每年的省份为决策单元，先计算含非期望产出的 SBM 效率；对位于效率前沿的省份再计算超效率值。默认使用代码内的线性规划求解程序；Pyomo/Ipopt 后端仅供可选的交叉核对。
4. `sbm_output.py`、`output_stata.py` 导出效率面板、汇总表和 Stata 长面板。`main.py` 串联上述流程；`output.py` 可单独导出碳排放量表。

`农业碳排放效率复现代码.do` 是研究阶段的 Stata 分析脚本，包含描述性统计、回归及稳健性分析。它不是运行 Python 计算流程所必需的文件，也不代表已发表的因果结论。

## 输入数据

完整运行需要自行取得有权使用的 Excel 数据，并按 `config.py` 中的文件名放入项目根目录下的 `data/`。该目录已被 `.gitignore` 排除，不随仓库发布。所需文件涉及 `Indicators`、`DEA_Inputs`、`DEA_Desirables` 和 `Controls`；政策冲击文件见 `Did_Variable` 配置。

每个输入工作簿使用 `Sheet1`：包含名为 `地区` 的列，以及 2011—2024 年的年份列；各文件应有相同顺序的 31 个省级地区，年份数据须为数值。具体文件名、指标单位与碳排放系数以 `config.py` 为准。

**仅克隆本仓库不能直接复算全部结果**，因为完整的原始 Excel 输入没有公开。研究其他年份或地区时，还需检查代码中固定的面板范围和数据校验条件。

## 运行

Python 计算流程使用 `numpy`、`pandas` 和 `openpyxl`：

```bash
python -m pip install numpy pandas openpyxl
python main.py
```

在放齐输入文件后，`main.py` 将在本地 `data/` 生成或更新：

- `efficiency_panel_results.csv`：逐年计算时写入的效率面板；
- `农业碳排放效率面板（2011-2024）.xlsx`：省份—年份效率值；
- `农业碳排放效率汇总（2011-2024）.xlsx`：年度、省份和区域汇总；
- `农业碳排放效率与控制变量（长面板）.dta`：供 Stata 使用的长面板。

如只需计算并导出农业碳排放量，可在准备好相应输入文件后运行 `python output.py`。

Stata 脚本使用了作者本机的文件路径，并调用 `reghdfe`、`outreg2`、`coefplot`、`winsor2`、`logout` 等扩展命令。它保留了研究阶段的写法，尚未整理为可从头直接运行的脚本；独立使用前需要调整路径、配置扩展命令并检查各分析步骤。
